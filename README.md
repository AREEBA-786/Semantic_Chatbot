# Semantic Search Chatbot

An intelligent Semantic Search & Q&A Chatbot built with Python, Hugging Face Sentence-Transformers, and Vector Embeddings. 
The chatbot uses the `distiluse-base-multilingual-cased-v1` model to convert questions into vector embeddings and identify the closest matching FAQ using semantic similarity.

## Key Features
- Meaning-based semantic search
- Finds relevant FAQs even when the wording is different
- Multilingual sentence embeddings
- Cosine similarity-based matching
- Interactive command-line chatbot

## 🛠️ Technologies Used
- Python
- Pandas
- Sentence Transformers
- Semantic Search
- Cosine Similarity
